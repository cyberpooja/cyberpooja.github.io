## About Me

I'm Puja, a Product Security Engineer with a strong interest in mobile application security, reverse engineering, AI security, and vulnerability research. My work involves understanding how applications function internally, identifying security weaknesses, and analyzing their root causes.

I primarily focus on **Mobile Application Security, Product Security, Web & API Security, and AI Security**, combining manual penetration testing, source code analysis, debugging, and security automation.

### Understanding What's Underneath

I enjoy exploring application internals, tracing execution flows, understanding how security controls are implemented, and identifying where they can fail.

My technical interests and experience include:

- **Mobile Application Security:** Android static and dynamic analysis, Frida instrumentation, root detection, SSL pinning, IPC, deep links, and WebView security.
- **Reverse Engineering:** APK analysis, JADX, Smali, runtime debugging, and application behavior analysis.
- **Product Security:** Source code review, vulnerability validation, root cause analysis, false-positive reduction, security remediation, and secure development practices.
- **Web Application Security:** OWASP Top 10, authentication, authorization, business logic vulnerabilities, and manual penetration testing.
- **API Security:** REST API testing, access control, authentication mechanisms, and API vulnerability assessment.
- **AI Security:** Exploring security risks in LLM-powered applications, prompt injection, insecure tool integrations, RAG security, sensitive information disclosure, and AI application attack surfaces.
- **Security Automation:** Developing Python-based security tools, vulnerability scanners, and scripts to improve security testing and analysis.

### How I Approach Research

My approach is straightforward: **understand the system, identify assumptions, test their boundaries, and investigate the root cause.**

I prefer hands-on experimentation, reproducible proof-of-concepts, and code-level analysis to understand not just whether a vulnerability exists, but why it exists.

Through this portfolio, I share my security research, technical findings, tools, experiments, and practical learning experiences, with the goal of making complex security concepts easier to understand.
